# ADR 0003 — Internationalisation et tokens

Statut : proposé, implémenté pour revue Lot 0.
Date : 2026-10-03

## Décision
Dictionnaires typés fr-FR/en-GB et primitives Intl ; tokens CSS centralisés.

## Motivation
Éviter textes dispersés et hypothèses françaises sans ajouter un routage multilingue prématuré.

## Conséquences
fr-FR affiché au Lot 0 ; intégration next-intl à décider avant préférences/routage utilisateur. Aucun couplage langue/devise/timezone.
